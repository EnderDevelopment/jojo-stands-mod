# JoJo Mod

A Minecraft mod featuring JoJo's Bizarre Adventure stands, including Star Platinum, The World, Killer Queen, Stone Free, Gold Experience, Steel Ball Run, King Crimson, and Hierophant Green. The mod also includes a Star Platinum pickaxe and block, and a Stand Menu GUI.

## Features
- Star Platinum pickaxe and block
- Various JoJo stands as items
- Stand menu GUI

## Installation
1. Download the mod jar file.
2. Place it in the `mods` folder of your Minecraft installation.
3. Launch Minecraft with the Fabric loader.

## Usage
- Use the Stand Menu Item to open the Stand Menu.
- Craft and use the Star Platinum pickaxe and block.
- Collect and use the various JoJo stands.
